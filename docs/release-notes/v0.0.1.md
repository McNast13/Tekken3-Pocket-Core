**Experimental** first preview of the **Tekken 3** arcade core (Namco System 12) for the Analogue Pocket, built on the
Namco System 11 port and the openFPGA PlayStation core. Expect rough edges: this is a test release, not a finished core.

**What works:** Tekken 3 boots and plays, with music, sound effects and all four attack buttons. The H8 sound and input
CPU is recreated in the FPGA and runs the game's own sound program. Test-menu settings are saved between launches.

**What had to give to fit the Pocket:** the real System 12 board needs more than the Pocket's FPGA holds, so this core
makes trade-offs to fit:
- **Tekken 3 only.** Everything other games need (security chips, gun board) is removed, and so are two graphics-chip
  features Tekken 3 never uses (line drawing and reading video memory back). Only the World version (TET2-VER.E1) is
  supported.
- **A slower CPU.** The real board's main CPU runs at about 50 MHz; the core's runs at the PlayStation's 33.9 MHz. The CPU
  turbo setting makes up some of the gap by skipping memory waits and adding a data cache ("Mem + compute + cache", the
  default and the fastest).
- **A slower graphics chip.** On heavy frames the graphics chip does not finish in time: the game slows down in places
  (King vs Xiaoyu is a clear example), and a fighter or the HUD can disappear for a single frame.
- **Not cycle-faithful.** The aim is to play Tekken 3 as close to the arcade as the Pocket allows; MAME remains the
  reference for accuracy.

**Install:** unzip onto the root of the SD card. The core appears under openFPGA > Arcade > Tekken 3.
No ROMs are included. You need MAME's `tekken3.zip` (Tekken 3, World, TET2-VER.E1) from a current MAME romset that you
own. Then run `tools/make_t3_roms.py` from this repository with Python 3 (nothing else to install):

    python3 tools/make_t3_roms.py --roms <folder with tekken3.zip> --sd <SD card root>

It checks every file in the zip and writes the game files (about 40 MB) to `Assets/tekken3/common/tekken3/` on the card.
If a check fails it names the file: the zip is from a different MAME version, a different Tekken 3 version, or damaged.
See the README's "Converting tekken3.zip" section for step-by-step instructions, Windows and troubleshooting.

**Known issues:**
- Not full speed: fights run at or close to 60 fps in some match-ups but slow down in heavier moments.
- A fighter or the HUD can vanish for one frame on heavy frames.
- The game used to freeze after a long time (the graphics chip waiting for words the game had cancelled). That is fixed
  in this release and has not recurred in testing on a Pocket so far (attract and full games), but long-term testing is
  still limited.
- The data cache behind "Mem + compute + cache" is experimental. If you see wrong graphics or hangs, try
  "Memory + compute" and please report it.
- Sound is close to MAME's by ear but not yet checked in detail.

This core is built with heavy use of AI (Claude, through Claude Code) under the project owner's direction, and is tested
on a real Pocket, not reviewed line by line by an expert. See the README's "Use of AI" section.
